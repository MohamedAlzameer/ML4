Real-Time Context-Aware Text Classification & Live Stream Routing

Machine Learning Project using Python & Scikit-Learn

Project Overview

This project automatically classifies customer feedback into the correct department, assigns a priority level, and routes each message in real time. The system uses Natural Language Processing (NLP), TF-IDF feature extraction, and Machine Learning models for accurate classification.

Features

  • Customer Feedback Classification
  • Real-Time Message Routing
  • Context-Aware Priority Detection
  • TF-IDF Feature Engineering
  • Model Comparison
  • Live Stream Simulation
  • Interactive Dashboard
  • Saved ML Model using Joblib

Dataset

Category Destination Team
Billing Finance Team
Delivery Logistics Team
Product Quality Assurance Team
Technical Support IT Support Team
General Inquiry Customer Care Team
